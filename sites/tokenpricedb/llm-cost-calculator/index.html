How the cost is calculated

Cost = input tokens ÷ 1,000,000 × input price + output tokens ÷ 1,000,000 × output price. Prices are standard pay-as-you-go list prices; batch, priority and long-context tiers are not included.

Token counts from pasted text use the o200k_base encoding. They are exact only for the OpenAI models labeled "exact" and an estimate for every other model, because each provider uses its own tokenizer.

5 models from the full database are left out of the tables because their providers have deprecated or retired them and their stored prices could not be confirmed on the providers' own pages.
