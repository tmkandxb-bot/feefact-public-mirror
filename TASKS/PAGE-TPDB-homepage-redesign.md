# PAGE-TPDB-homepage-redesign — TokenPriceDB 首页视觉升级

站点：仓库 `sites/tokenpricedb/`（已上线 https://tokenpricedb.com）
负责人：Page Builder；QA Reviewer 审；Remy 终审后部署。**不许自合并。**

## 目标

现首页数据齐全但观感像一张裸表格，单调。本次只做视觉与布局升级：科技感、大局感、层次分明、有主题图片和配色系统。**计算器功能、全部价格数据、单模型页一律不动。**

对标参考（只学布局与层次，不抄文案/图片）：CostGoat 的计算器站群首页——强 Hero（标题 + 计算器入口 + 视觉元素）、彩色分类卡片、数据区块有节奏地交错、深色科技风打底。

## 硬约束（红线）

1. `data/models.json`、`data/price-changes.json` 一个字节都不许改；43 个单模型页、compare 页、两个 calculator 落地页不在本次范围。
2. 首页计算器的 JS 逻辑与输入输出钩子原样保留，只许换它周围的版式与样式。
3. **图片里不许出现可读的数字、价格、模型名**——本站卖点是数据可信，图里出现任何看似价格的数字都算造假。图表类视觉只用抽象色块/线条，不带刻度文字。
4. title/meta、URL、已有内链结构不许动。

## 图片（用 Fable 5.2 生成，共 3 张）

在 Devin 环境里用 Fable 5.2 生成，存到 `assets/img/`，转 WebP，每张 ≤250KB（Hero ≤400KB），写描述性 alt、加 width/height，首屏以下 lazy-load。

1. **Hero 主视觉**（横版宽幅）：深色科技风抽象图——发光的代币/数据流汇入一个数据库圆柱体，蓝紫渐变光效，干净高级，不要卡通感。用作 Hero 背景或右侧主视觉。
2. **比价段配图**（横版）：抽象柱状图意象——高低不同的发光柱体排成天际线，深底蓝紫光，**无任何数字和文字**，放在 compare/cheapest 引导段旁。
3. **价格变动段配图**（小幅）：抽象折线走势 + 铃铛意象的扁平科技插画，深底，与全站配色一致，放在 price-changes 引导段旁。

**若你的环境里 Fable 5.2 生成不了图片：停下、在 PR 里说明，不要用图库照片、不要用占位图、不要外链图片。** 回报 Anita 转 Remy 处理。

## 布局与配色要求

- 配色系统：深蓝紫底（Hero 与数据带）+ 青蓝强调色 + 白/浅灰内容区交替，至少 3 个明暗层次；模型家族用彩色小标签/卡片头区分（OpenAI / Anthropic / Google / 开源各一色，全站统一）。
- Hero：大标题 + 一句主张 + 计算器入口按钮 + 主视觉，首屏就要有「数据库」体量感：可加一条实时感数据带（43 个模型 / 4 家厂商 / 价格带官方出处 / 变动历史可查——数字必须与站内真实数据一致）。
- 模型总表：斑马纹 + 家族色标 + 表头吸顶（桌面端），不再是一张素表；表格数据与排序逻辑不动。
- 计算器区块、比价引导、价格变动引导三段用底色/图片交错出节奏；卡片规范全站统一（圆角、边框、标题色）。
- 移动端：表格可横滚但页面本身不横滚，Hero 图不压字。

## 补充要求（号主追加）

图片要当点击钩子 + 谷歌图片收录资产，不只是装饰。

1. 关键图（尤其 Hero）用标准 img 标签，不用 CSS 背景图；Hero 图可点击、锚到工具区（本站锚到计算器）。
2. 文件名用英文关键词（如 llm-api-token-price-database.webp），不许 img1 这类名字。
3. alt 写自然的目标词句子，不堆砌。
4. Hero 图至少 1200px 宽，其余至少 800px。
5. sitemap.xml 加 image:image 图片条目（没有 sitemap 就建，含主要页面 URL）。模型页只放索引页和两个计算器落地页，不用全量 43 页。
6. Hero 图设为 og:image。
7. 生图工具（Remy 2026-11-21 批准）：可用现有生图工具，PR 里注明「模型未标明」；两件共六张图（本件三张）照任务文件的构图要求生成，由 Remy 验收，不合格不上线。

本站特有：图里无数字红线不变，数字只进 alt 和正文真实数据。
