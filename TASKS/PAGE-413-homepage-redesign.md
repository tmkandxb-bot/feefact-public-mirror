# PAGE-413-homepage-redesign — MyForm413 首页视觉升级

站点：https://myform413.com（源码现状以线上页面为准，先完整读取线上首页 HTML/CSS 再动手）
负责人：Page Builder；QA Reviewer 审；Remy 终审后移植上线。**不许自合并。**

## 目标

现首页内容齐全但观感单调、像静态页。本次只做视觉与布局升级：有大局感、层次分明、有主题图片和配色系统。**功能、文案事实、价格、向导逻辑一律不动。**

对标参考（只学布局与层次，不抄文案/图片）：statementsready.com、form413.com 的首页——人家的做法是：强视觉 Hero（真人场景图 + 大标题 + 双 CTA）、信任带、图文交错的功能段、深色区块制造节奏、对比表和定价卡有明显的卡片层级。

## 硬约束（红线）

1. **六步向导区块的 HTML 结构、id/class 钩子和全部 JS 原样保留，一字不改**——它连着浏览器内填 PDF 的逻辑，改坏了整个产品就废了。你只能重做向导区块之外的部分，并保证向导的 CSS 钩子不被你的新样式污染。
2. 已核实的事实与数字不许改：官方 05-24 版、147 字段、$29 / 首单 $19、竞品价 $49 / $79、FY2025 SBA 7(a) 77,600 笔（可用作数据带，须注明出处口径为 SBA 公开数据）。
3. FAQ 的 JSON-LD、页面 title/meta description、现有 URL 不许动。
4. 图片里不许出现可读文字（生成图的文字必错位/拼错），尤其不许出现金额、利率、表格数字。

## 图片（用 Fable 5.2 生成，共 3 张）

在 Devin 环境里用 Fable 5.2 生成，存到交付目录 `assets/img/`，转 WebP，每张 ≤250KB（Hero ≤400KB），全部写描述性 alt、加 width/height 属性防布局抖动，首屏以下 lazy-load。

1. **Hero 主图**（横版）：小企业主在明亮的办公室里对着笔记本电脑核对一份财务报表，桌上有文件夹和计算器，神情专注放松；写实摄影风，暖色调，画面右侧留白方便叠标题（或标题在左图在右的双栏布局）。
2. **中段图**（横版）：银行贷款经理与申请人隔桌沟通、桌上摊开文件，气氛专业友好；写实摄影风，与 Hero 同色调。
3. **点缀图**（小幅）：扁平插画风的「文件清单/文件夹」主题，蓝绿配色，与全站配色系统一致，放在三步流程或 FAQ 段旁。

**若你的环境里 Fable 5.2 生成不了图片：停下、在 PR 里说明，不要用图库照片、不要用占位图、不要外链图片。** 回报 Anita 转 Remy 处理。

## 布局与配色要求

- 配色系统：金融感深蓝（主色）+ 青绿（强调）+ 浅灰蓝（区块底色），正文区白底与浅色底交替，深色数据带压阵——至少 3 个明暗层次，不许全站一面白。
- Hero：双栏（左文案右图）或全宽图 + 渐变罩，大标题字号明显拉开层级，信任条保留在顶部。
- 新增**数据带**（深色整幅）：77,600 笔 FY2025 7(a) 贷款 / 每位 ≥20% 股东必交一份 / 官方 05-24 现行版 / 浏览器内完成不上传——四格并排，大数字小说明。
- 功能四卡、对比表、定价卡：统一卡片规范（圆角、边框/阴影、标题色），对比表里 MyForm413 列用强调色高亮。
- 段与段之间用底色或图片形成节奏；移动端单列不塌、不横滚。
- 底部常驻 CTA 条保留。

## 补充要求（号主追加）

图片要当点击钩子 + 谷歌图片收录资产，不只是装饰。

1. 关键图（尤其 Hero）用标准 img 标签，不用 CSS 背景图；Hero 图可点击、锚到工具区（本站锚到六步向导）。
2. 文件名用英文关键词（如 sba-form-413-filled-sample.webp），不许 img1 这类名字。
3. alt 写自然的目标词句子，不堆砌。
4. Hero 图至少 1200px 宽，其余至少 800px。
5. sitemap.xml 加 image:image 图片条目（没有 sitemap 就建，含主要页面 URL）。
6. Hero 图设为 og:image。

本站特有：Hero 图里的报表做虚化预览式构图（看得出是填好的报表版式、文字数字不可读），与无文字红线不冲突。
